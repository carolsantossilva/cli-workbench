# Server ownership

This area owns Go server code only. Read the root `AGENTS.md`, this file, and `.agents/skills/station-server/SKILL.md` before changing it. Check the actual Go toolchain and `go.mod` before running Go commands; do not invent a module path or run `go mod init`, `go get`, or downloads implicitly. Keep mobile/web changes out of scope unless the approved design and workflow `writePaths` explicitly include them.
