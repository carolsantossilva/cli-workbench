# Workbench workspace

This repository is a mobile, web, and server monorepo scaffold. It contains the versioned workspace contract and local AI instructions; it is not an application template and has no installed dependencies.

Start Codex from this directory, review `workspace.json`, and read the `AGENTS.md` for the project area before making changes. Choose frameworks, versions, dependencies, and commands only through an approved design and explicit workspace-manifest updates.

The scaffold includes an optional `adr-authoring` skill for recording consequential decisions. Existing project conventions and the workflow paths in `workspace.json` still govern where an ADR can be read or written.
